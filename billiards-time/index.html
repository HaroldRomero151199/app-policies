Política de Privacidad de Billiards Time: Calculadora de Billar

SagraSoft ("nosotros") desarrolla la aplicación Billiards Time como una aplicación gratuita. Este servicio se presta sin costo alguno y está diseñado para ser utilizado tal cual.

1. Recopilación y uso de información

Billiards Time es una herramienta que realiza cálculos de forma local en el dispositivo del usuario. Esta aplicación NO recopila, NO almacena, NO transmite ni comparte ningún tipo de información personal, datos sensibles del usuario, ni identificadores del dispositivo con servidores externos ni terceras partes.

2. Almacenamiento Local

El precio por hora introducido por el usuario se almacena localmente en el dispositivo mediante almacenamiento persistente propio del sistema operativo (SharedPreferences/LocalStorage) con el único fin de evitar que el usuario tenga que reescribirlo. Estos datos no salen del dispositivo.

3. Privacidad Infantil

Estos servicios no abordan a nadie menor de 13 años. No recopilamos a sabiendas información de identificación personal de niños.

4. Cambios a esta Política de Privacidad

Es posible que actualicemos nuestra Política de privacidad de vez en cuando. Se le recomienda revisar esta página periódicamente para ver cualquier cambio.
